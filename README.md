# Ripe · Конструктор грядки (экраны 2.1–2.3)

Интерактивный прототип внутренней страницы сервиса: план посадок для 4 ячеек на площадке «Опушка».
Чистые HTML/CSS/JS, без сборки и зависимостей. Шрифт Inter подключается с Google Fonts. Если его нет, страница покажет системный шрифт.

## Файлы

| Файл | Что внутри |
|---|---|
| `constructor.html` | Разметка: шапка, экран 2.1 и модалки 2.2 (карточка культуры) и 2.3 («Кто посадит?») |
| `constructor.css` | Стили. Серые lo-fi токены собраны в `:root` в начале файла |
| `cultures.js` | Данные: культуры, зоны, площадки, стартовый набор, ссылка на главную |
| `constructor.js` | Логика страницы |

## Как подключить

1. Положить все 4 файла в репозиторий **в одну папку** с `index.html` (главная страница).
2. Открыть `constructor.html` в браузере. Сервер не нужен, работает и с диска.
3. Если главная лежит не в `index.html`, поменять путь в `cultures.js` → `mainPageUrl`.
   Он подставляется в логотип «Ripe» в шапке.
4. Чтобы перейти с главной в конструктор, нужна ссылка: `<a href="constructor.html">…</a>`.

## Что работает

- **Поиск по культурам** и фильтр по категориям (Все / Быстрые / Зелень / Овощи / Ягоды). Список прокручивается.
- **Распределение по ячейкам.** Кнопка «+» ставит культуру в свободную ячейку. Культуру можно перетащить на любую ячейку, тогда она заменит то, что там было. «✕» освобождает ячейку. Ячейки сами группируются по зонам: теплица, ягоды, открытый грунт.
- **Подсказки** пересчитываются при каждом изменении: зона и почему, хорошие и плохие соседи, разная влажность для огурца и томата, ремонтантная клубника, опора для гороха, многолетняя малина, повторы, сложные культуры, нет быстрых культур, все ячейки заняты.
- **Сводка:** урожай по культурам, итог и дата первого урожая.
- **Стартовый набор / Свой выбор.** Стартовый набор нельзя редактировать. Свой план сохраняется при переключении.
- **Экран 2.2.** Клик по названию культуры открывает карточку: факты, соседи, кнопка «Добавить в ячейку».
- **Экран 2.3.** «Сохранить план» спрашивает, кто посадит (сам или садовник) и когда (сезон с 15 мая по 30 июня; если он уже прошёл, предлагается следующий год). После этого под кнопкой появляется статус.
- **Выпадающий список площадок.** Активна только «Опушка», остальные показаны, но выбрать их нельзя.
- Модалки закрываются по Esc, клику по фону и ✕. Фокус остаётся внутри модалки.

## Что намеренно отключено

- Пункты меню «Моя грядка», «Календарь», «Огород», «Урожай» — это `<span>` без ссылок, по ним нельзя кликнуть.
- Колокольчик, аватар и кнопка «Спросить агронома» стоят в `disabled`.
- Единственная активная ссылка в шапке — логотип «Ripe», он ведёт на главную.

> Если главной должна быть «Моя грядка», а не логотип, замените этот `<span>` в `constructor.html` на `<a href="index.html" class="nav__item">Моя грядка</a>`.

## Ограничения

- Данные демонстрационные и живут только в памяти: после перезагрузки план возвращается к исходному.
- Вёрстка рассчитана на десктоп (минимальная ширина 1200 px).
- Перетаскивание работает мышью. С клавиатуры и на тачскрине культуру добавляют кнопкой «+».
