# Ripe

Статический сайт без сборки: главная и прототип «Конструктор грядки».
Шрифт — Inter с Google Fonts (подключается в `stylesheets/font.css`).

## Структура

```
Ripe/
├── index.html            главная
├── constructor.html      конструктор грядки
├── img/                  logo.svg (заглушка), vk.svg, tg.svg
│   └── seeds/            картинки семечек (svg/png) — сейчас заглушки
├── scripts/
│   ├── cultures.js       данные: культуры, зоны, площадки, mainPageUrl
│   ├── header.js         шапка: бургер-меню, выбор площадки (на всех страницах)
│   ├── constructor.js    логика конструктора
│   ├── seed-config.js    список путей до картинок семечек
│   ├── subscribe.js      уведомление «Вы подписаны» на главной
│   ├── seeds.js          семечки на фоне главной (настройки в начале файла)
│   └── splash.js         заставка: быстрая смена семечек (настройки в начале файла)
└── stylesheets/
    ├── style.css         точка входа — HTML подключает только его
    ├── font.css          шрифт (единственное место для смены)
    ├── base.css          токены, сброс, типографика
    ├── header.css        шапка и меню
    ├── splash.css        заставка
    ├── home.css          стили главной (body.home)
    ├── constructor.css   стили конструктора
    └── adaptive.css      адаптив, подключается последним
```

## Правила

- Новая страница: `<link rel="stylesheet" href="stylesheets/style.css">`, скрипты `cultures.js` и `header.js`, шапка копируется из `index.html`.
- Стили страницы живут в своём файле и привязаны к классу страницы (`.home`, `.page--constructor`), чтобы не перебивать общие токены.
- Шапка: доступный пункт меню — `<a class="nav__item">`, недоступный — `<span class="nav__item is-disabled">`. Текущая страница — `is-active` и `aria-current="page"`.
- Мобильное меню включается при ширине ≤ 1024 px: остаются логотип и бургер.

## Ограничения

- Страница конструктора рассчитана на десктоп (минимальная ширина контента 1200 px); на экранах уже 1200 px она прокручивается в бок внутри своего блока, раскладка не перестраивается. Адаптирована только шапка.
- Данные демонстрационные и живут в памяти.
